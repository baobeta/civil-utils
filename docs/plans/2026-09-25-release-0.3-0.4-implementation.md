# Release 0.3–0.4 Implementation Plan (R1–R10 of the roadmap)

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. One implementer per task, review after each, Release build of the add-in at 0 warnings and `dotnet test C3DTools.Core.slnf` green before the next task.

**Goal:** ship the ten daily-use commands from `2026-09-25-roadmap-0.3-plus.md` (R1–R10), each with its own easy dialog, ribbon button, preview/apply/single-undo and XData-tagged output, without any Windows/Civil 3D run during development.

**Architecture:** unchanged from 0.2. Core (netstandard2.0) holds all math/text/table builders and every dialog's view model (`INotifyPropertyChanged`, unit-tested). Host (net48) holds thin code-only WPF windows built on one shared `ToolWindow` base, readers of drawing objects, writers of plain entities, and the ribbon. Everything risky in the 2021 API is wrapped so a failure prints a Vietnamese message and leaves the drawing unchanged.

**UI rules (apply to every command — the user asked for this explicitly):**

1. Every command opens a dialog first; nothing happens on the command line except picks and the `Giữ kết quả? [Co/Khong]` preview question.
2. Same skeleton everywhere (`Ui/ToolWindow`): title bar text = command purpose in Vietnamese; top area = source/selection with **Chọn trên bản vẽ…**; middle = the one grid or option list; bottom-left = summary line; bottom-right = **Xem trước**, **Áp dụng** (disabled while invalid), **Hủy**; Esc = Hủy; Segoe UI; sensible default size; remembers last size per command (registry key `HKCU\Software\C3DTools\<cmd>`).
3. Every numeric field accepts a comma or dot (`NumberInput`). Invalid text keeps the text, marks the row/field red, disables Áp dụng.
4. Output checkboxes are named for what they produce (`Khung`, `Cọc`, `Bảng`, `CSV`, `Excel`) and their last state is remembered.
5. A preset (`*.c3dtools.json` next to the drawing, else the bundled default) fills every default; the dialog shows which preset is in use.
6. Ribbon: one tab **C3DTools**, panels **Tuyến**, **Trắc dọc**, **Trắc ngang**, **Địa hình**, **Thoát nước**, **Bản vẽ**. Large button = the daily command of the panel; the rest small. Tooltip = one sentence in Vietnamese.

**Tech:** as 0.2 (net48 x64 host, code-only WPF, `AutoCAD.NET` 24.0.0 + `Civil3D2021.Base` compile-only, xUnit Core tests). New: `System.IO.Compression` (in-box) for XLSX.

## T3 — R1 `CTFONT`

**Core** `Text/VietFontCodec.cs`: `Encoding { Unicode, Tcvn3, Vni }`; `Detect(string)`; `ToUnicode(string, Encoding)`; `FromUnicode(string, Encoding)`; `ConvertMText(string, from, to)` that tokenises MText control codes (`\P`, `\L`, `\O`, `\f…;`, `\H…;`, `\C…;`, `\W…;`, `\Q…;`, `\A…;`, `\S…;`, `{`, `}`, `\\`, `\{`, `\}`, `%%d/%%c/%%p/%%u/%%o`) and converts only the visible runs; the `\f` font name is replaced by the preset target font when converting to Unicode. Tables: TCVN3 (ABC) upper/lower mapping (134 glyphs + the 5 uppercase-only slots), VNI-Windows two-byte composition (base letter + tone/hat combining char). Tests: full alphabet round trip both ways; "Ti\xAAu chu\xC8n" → "Tiêu chuẩn" (TCVN3); "Tieâu chuaån" → "Tiêu chuẩn" (VNI); MText `{\fVnTime|b0|i0|c0|p34;C\xB6ng}` → `{\fArial|b0|i0|c0|p34;Cống}`; detection picks Vni for "ñöôøng", Tcvn3 for "®­êng", Unicode for "đường".

**Host** `Commands/FontCommand.cs` + `Ui/FontWindow.cs` (on `ToolWindow`): source = selection or whole drawing (radio); detected encodings summary (counts per encoding per object type: DBText, MText, AttributeReference, AttributeDefinition, Dimension override, MLeader, Table cells); options: target encoding (default Unicode), replace text style font (checkbox, font name from preset), also convert block definitions (checkbox). **Xem trước** shows the first 20 conversions as before/after in the dialog (no drawing change); **Áp dụng** converts in one transaction under lock; summary `Đã chuyển n đối tượng`. One undo. Ribbon panel **Bản vẽ**, large button **Chuyển font**.

Commit: `feat: CTFONT Vietnamese font code conversion`.
